# 口播结构诊断标准

## 使用目的

用于判断时长、开头方向和内容节点，也用于口播文案生成时的时间分配。

## 2 分 30 秒结构

1. 0–3 秒：冲突或痛点
2. 4–30 秒：具体场景
3. 31–90 秒：核心机制
4. 91–120 秒：判断标准或行动
5. 121–150 秒：真实下一步

## 2 分钟结构

1. 0–3 秒：冲突
2. 4–25 秒：场景
3. 26–75 秒：核心机制
4. 76–100 秒：判断或行动
5. 101–120 秒：真实下一步

## 60 秒结构

1. 0–3 秒：冲突
2. 4–15 秒：场景
3. 16–45 秒：核心判断
4. 46–60 秒：动作与下一步

## 诊断规则

- 整条内容只保留一个核心判断。
- 开头必须与核心观点直接相关。
- 中段必须解释“为什么”，不能只重复结论。
- 行动必须具体到今天能做。
- 下一步只能对应真实存在的产品、服务、社群、关注或评论动作。
- 后果只能来自现实因果，不能虚构灾难。
- 转化入口必须符合 [platform-compliance.md](platform-compliance.md)。

## 输出方式

只输出结构节点，例如：

> 收入上涨的具体现象 → 消费边界同步扩大 → 储蓄没有被提前分配 → 检查三个月账单 → 设置固定储蓄动作

不得把节点扩写成连续正文或逐字稿。
