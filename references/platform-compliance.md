# 平台合规：封建迷信、占卜与预测

## 使用原则

生成任何公开发布的标题、封面文案、选题、口播、评论区回复或 CTA 前必须读取本文件。

平台规则会更新。用户指定平台且宿主可以联网时，优先查询该平台最新官方规则；无法查询时，执行本文件的最严格共同标准。合规不等于保证过审，最终以平台实际审核为准。

## 统一禁区

不得创作、包装、推广或引流至以下内容和服务：

- 算命、测算、占卜、抽签、运势、流年、命理、八字、紫微斗数、手相、面相。
- 塔罗算命、塔罗测运势、预测复合、预测婚姻、预测桃花或正缘、推测对方内心和未来结果。
- 风水改运、开运转运、招财旺运、消灾化煞、法事、符咒、通灵、前世、业力、诅咒。
- 把星座、牌面、能量、磁场、宇宙信号或超自然力量说成能够确认事实、诊断问题、治疗疾病或决定人生结果。
- “包复合”“一定遇到正缘”“近期必有桃花”“不处理就会失去他”等确定性承诺或恐吓。
- 利用重病、丧亲、失恋、破产、焦虑等脆弱状态高压成交。

禁区覆盖免费内容、付费内容、课程、咨询、社群、直播、小程序和私域引流。不得用谐音、拼音、拆字、符号、暗语、遮挡、隐喻或“仅供娱乐”等声明掩盖实质上的预测、测算或迷信服务。

## 可以保留的内容

可以讨论现实中的情感、家庭教育和焦虑问题，但必须落在：

- 当事人已经说出的事实和可观察行为。
- 沟通模式、关系边界、需求表达、风险识别和个人选择。
- 非医疗性质的情绪梳理、写作反思和自我提问。
- 对塔罗、命理或民俗的历史、文化、艺术或批判性讨论，但不宣传其真实效力，不提供个体预测，不承接相关服务。

不得把普通咨询包装成心理治疗。涉及精神疾病、自伤、暴力、未成年人安全或其他高风险问题时，建议寻求现实中的可信支持、正规医疗或相应专业机构。

## 自动改写

遇到违规原命题时，不复述并强化违规卖点，保留真实烦恼后直接换成合规问题：

| 违规原命题 | 合规改写方向 |
| --- | --- |
| 测他还爱不爱我 | 从联系频率、承诺兑现和冲突处理判断关系投入 |
| 占卜我们会不会复合 | 梳理复合需要满足的现实条件，以及自己能控制的选择 |
| 看近期桃花运、正缘何时出现 | 识别自己反复进入不合适关系的模式，建立筛选标准 |
| 测孩子未来运势 | 观察孩子当前行为、学习环境和亲子沟通中的具体问题 |
| 抽到某张牌说明什么 | 删除牌面预示，改为一个能帮助当事人澄清处境的自我提问 |
| 改运、清理负能量 | 改成调整可执行的环境、习惯、边界和求助方式 |

改写后不得残留“暗中还是在预测”的结构。结论只能来自事实、行为和明确的因果推理。

## CTA 规则

- 可以推广真实存在且内容合规的关系梳理、沟通支持、选择澄清或内容社群。
- 不得推广或变相承接塔罗测算、运势预测、占卜、算命、改运等服务。
- 不得承诺咨询能够复合、脱单、遇见正缘、改变命运、消除疾病或获得确定结果。
- 后果型 CTA 只能指出继续回避、试探或缺乏沟通的现实代价，不得引用牌面、命运或超自然后果制造恐惧。
- 如果用户实际提供的是平台禁止的服务，不帮助更名、伪装或设计绕审话术；改为建议其调整真实服务内容。

## 发布前检查

逐项静默检查标题、封面、字幕、口播正文和 CTA：

1. 是否出现禁区词语或同义变体？
2. 是否预测未来、读取他人内心或制造超自然因果？
3. 是否用免责声明掩盖实质测算？
4. 是否承诺确定结果或利用脆弱状态高压成交？
5. 是否把违规服务换名后继续导流？
6. 所有结论是否都能由可观察事实和现实因果支持？

任一项不合格，先自动修正诊断方向，再交付五项诊断；不得扩写成完整文案。
