# 开头优化标准

## 使用目的

优化口播文案的开头，生成多个可选方案，找出最有吸引力的版本。

## 核心原则

### 开头是内容的试用装

开头必须独立工作。不能假设观众看了标题或封面。5 秒内独立建立吸引力。

### 开头公式

```
开头 = 话题（讲什么）+ Hook（为什么看）+ 可信度（为什么信你）
```

示例：
- 话题：提前还房贷
- Hook：60 个家庭只有 5 个适合还
- 可信度：我在券商做了 8 年固收研究
- 完整开头：「我给 60 多个家庭做过现金流梳理，问我要不要提前还房贷的有 20 个，最后真正适合还的不到 5 个。」

### 悬念优先

制造悬念，不直接给答案。用"为什么"引导，不用"证明"收束。

- 错误：提前还房贷不划算，因为你会失去流动性。← 直接给了答案
- 正确：我见过太多人还完那一笔，三个月后被裁员，手里一分钱调不出来。← 留悬念

### 口播友好

能直接对着镜头念出来。不用自问自答、不用书面语、不用抽象概念开场。

## 诊断维度

对现有开头做六维检查：

| 维度 | 检查项 |
|---|---|
| 独立性 | 不看标题能理解吗？ |
| Hook | 前 5 秒有抓手吗？ |
| 悬念 | 有没有直接给答案？ |
| 可信度 | 为什么听你讲？ |
| 口播友好 | 能直接念出来吗？ |
| 匹配度 | 开头承诺的，正文能兑现吗？ |

## 三种生成方法

### 方法一：素材提取

从文案中提取现有素材，按优先级排序：

| Hook 类型 | 优先级 | 说明 |
|---|---|---|
| 晒结果 + 反转 | ★★★★★ | 用真实成绩建立可信度，再制造好奇 |
| 数据冲击 | ★★★★ | 大数字、对比数字、百分比 |
| 反差/转变 | ★★★★ | 之前 vs 之后，反差越大越好 |
| 金句 | ★★★★ | 能独立成立的观点，有记忆点 |
| 权威 + 观点 | ★★★ | 权威人物或机构背书 |
| 痛点 + 悬念 | ★★★ | 目标人群的焦虑 + 留悬念 |

基于提取的素材，生成 3–5 条开头。

### 方法二：素材增补

文案素材不够时，基于用户已确认的真实信息增补：

- 真实数据或结果（不编造）
- 具体案例或对比
- 反常识的结论

基于增补的素材，生成 3–5 条开头。

### 方法三：悬念制造

把结论改成问题，制造好奇心：

- 不要直接给答案
- 用"为什么"而不是"证明"
- 用"问题"而不是"结论"

基于悬念制造，生成 3–5 条开头。

## 输出格式

每种方法各生成 3–5 条，总共 10–15 条。最后选出 Top 3 推荐，每条说明理由和优势。

```markdown
## 开头优化方案

### 当前开头诊断
{六维检查结果}

### 方法一：素材提取（X 条）
| 序号 | 开头 | 用了什么素材 |
|---|---|---|

### 方法二：素材增补（X 条）
| 序号 | 开头 | 增补了什么 |
|---|---|---|

### 方法三：悬念制造（X 条）
| 序号 | 开头 | 制造了什么悬念 |
|---|---|---|

### Top 3 推荐
推荐 1：{开头} — 理由：{为什么推荐}
推荐 2：{开头} — 理由：{为什么推荐}
推荐 3：{开头} — 理由：{为什么推荐}
```

## 禁止事项

- 不在内容质量不过关时强行优化开头——开头是内容的试用装，内容没价值，优化开头没意义。
- 不生成书面语、自问自答的开头。
- 不生成直接给答案、没有悬念的开头。
- 不假设观众看了标题。
- 不编造用户没有的数据和经历。
